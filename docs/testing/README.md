# 報工系統的軟體測試（STLC）

## STLC 是什麼

STLC（Software Testing Life Cycle，軟體測試生命週期）就是「測試要照什麼順序做」。
它跟寫程式一樣有階段，每個階段都要交出一份東西，下一階段才有依據。

用蓋房子來比喻：

| 階段 | 蓋房子 | 報工系統 | 交出來的東西 |
|---|---|---|---|
| 1. 需求分析 | 看設計圖，列出要驗收的項目 | 從規格整理出「要驗證的規則」 | [01-需求追溯表](01-需求追溯表.md) |
| 2. 測試計畫 | 決定誰驗收、哪天驗、驗哪些 | 範圍、方法、環境、什麼時候算測完 | [02-測試計畫](02-測試計畫.md) |
| 3. 測試案例設計 | 寫驗收清單，例如「水龍頭打開要有熱水」 | 每條規則寫出步驟與預期結果 | [03-測試案例](03-測試案例.md) |
| 4. 測試環境建置 | 先接好水電才能驗 | 準備一個專門測試用、可以隨便弄亂的資料庫 | [04-測試環境](04-測試環境.md)、`mes_test`、測試程式 |
| 5. 測試執行 | 一項一項打勾，壞了就報修 | 執行測試，失敗就寫 Bug 報告，修好再測 | 測試結果、[Bug 紀錄](bugs.md) |
| 6. 測試結案 | 交屋報告 | 驗了幾項、過幾項、還有什麼風險 | [06-測試總結報告](06-測試總結報告.md) |
